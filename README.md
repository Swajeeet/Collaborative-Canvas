# CollaborativeCanvas

A real-time collaborative whiteboard built with React and Spring Boot.

## Tech Stack

**Frontend:** React (Vite), Tailwind CSS, STOMP.js, HTML5 Canvas

**Backend:** Java 17+, Spring Boot 3.x, Spring WebSocket (STOMP)

## How to Run

**Backend Server:**
```bash
cd server
./mvnw spring-boot:run
```

**Frontend Client:**
```bash
cd client
npm install
npm run dev
```
